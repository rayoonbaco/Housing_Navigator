# How we built and checked Housing Navigator

This records project design choices and evidence. It does not claim that the techniques are new inventions or that model reviews establish legal truth.

## Start with the resident, keep the audit underneath

The main view answers six everyday questions. The evidence view preserves source passages, dates, reviewed coverage and remaining uncertainty. “Check my homework” connects an explanation to its particular supporting rule and receipt. The Bill X-ray handoff informed this interaction; imported examples and code require their own safety and exact-quotation checks.

## Select evidence before explaining it

Extraction selects IDs from pinned source passages. The program copies passage text instead of silently repairing a model-generated quotation. Candidate rules face schema and exact-evidence checks before an independent review. A failed check stays failed and its record is preserved.

## Separate property coverage from a triggering event

A rental rule can govern what happens if a landlord takes an action without proving the landlord has already taken that action. Genuine property exemptions still require facts. Missing owner status, certificate dates or legally relevant residential definitions cannot be invented from a generic apartment label.

## Use three-valued decisions

Coverage evaluates true, false or unknown. An unknown exemption remains unknown. Postal city is kept separate from legal city. A matched county is geography, not evidence that every county law has been obtained. Source, date and independent-review gaps remain distinct from missing property facts.

## Treat overlapping laws as a reviewed relationship

A stronger-sounding rule or smaller numeric cap cannot automatically replace another law. Proposed controlling-law relationships need source evidence, matching property coverage and date gates. An unknown local rule cannot override a confirmed state rule. Unreviewed interactions are exposed for review.

## Keep dates and change notifications honest

Current, future, pending and failed measures have different meanings. A potential change notification is not confirmed eligibility. In the saved v2.3 run, T2 reported 88 potential notifications and zero confirmed eligible addresses; passing its boundary check does not satisfy every applicability expectation. Pending T4 results describe a hypothetical scenario, not current protections.

## Review the strategy before spending on more batches

Three internal reviewers separately inspected challenge compliance, evidence behavior and resident usability. External Claude critique was captured with request, response and usage receipts. A first attempt exhausted its output allowance on thinking; a corrected attempt returned a complete critique. The reconciliation records accepted advice, modified recommendations and corrections grounded in saved project evidence.

## Parallel work, one integration owner

Source acquisition, interface work and presentation preparation used separate additive packages. In the current pass, T2, interaction handling and resident UI use isolated working directories. The coordinator merges outputs and checks contracts, rather than allowing parallel tasks to overwrite the same release.

## Record exactly what a test proves

Offline fixtures establish specified code behavior, saved API runs establish recorded outputs, browser tests establish observed interactions and deployment checks establish public accessibility. None alone measures legal accuracy. Test counts are recorded with their scope; unresolved requirements appear in the gap ledger.

## Preserve the trail

Each run uses a unique output directory. Existing source inventories, failed candidates, logs and paid-call receipts remain intact. Private API credentials stay in the local PowerShell process and never enter the static website or repository. Release files receive hashes; the publication gate checks all 500 addresses and rejects pending or failed measures represented as current law.

## Commercial hypothesis

Residents need readable explanations; organizations may pay to maintain reviewed evidence and change histories for address portfolios. This is a proposed business model. Customer demand, pricing and revenue remain unvalidated.
